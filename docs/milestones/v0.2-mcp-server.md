# 🛠️ Milestone v0.2: MCP Server & Skills

## 📋 Objetivo
Construir o microserviço `apps/mcp-server` baseado no **Model Context Protocol (MCP)**, responsável por expor com segurança e padronização as ferramentas (Skills) que o agente utilizará para interagir com o ambiente local e serviços externos.

---

## 🛠️ Componentes & Skills Incluídos

1. **Servidor MCP Python**: Servidor assíncrono baseado no SDK oficial do MCP.
2. **Skill: System Filesystem**: Operações controladas de leitura, escrita, busca e manipulação de arquivos locais dentro de um diretório sandbox.
3. **Skill: Google Workspace**:
   * **Google Calendar**: Consulta, criação e atualização de eventos de agenda.
   * **Gmail**: Leitura, busca e rascunho de e-mails.
4. **Skill: VS Code Context**: Leitura de estrutura de diretórios de código e status do workspace ativo.
