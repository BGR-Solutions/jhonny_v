# Milestones & Roadmap

This directory outlines the project roadmap organized by milestones.

## Milestone Structure

Each milestone defines:
- **Objectives**: What we're trying to achieve
- **Deliverables**: Concrete artifacts/features
- **Issues**: GitHub issues linked to this milestone
- **Timeline**: Target completion date

## How to Use This Roadmap

1. **Planning a feature?** Add it to the appropriate milestone
2. **Prioritizing work?** Follow milestone sequence (v0.1 → v0.2 → v1.0)
3. **Checking progress?** See which issues are open vs. closed in each milestone
