# 🖥️ Milestone v0.5: Interfaces & Integrações de Cliente

## 📋 Objetivo
Conectar e homologar as interfaces de usuário finais ao ecossistema `jhonny-v`, garantindo uma experiência fluida tanto em chat web quanto no ambiente de desenvolvimento do VS Code.

---

## 🛠️ Interfaces Atendidas

1. **Open WebUI**: Contêiner com a interface web oficial configurado para apontar para o `agent-orchestrator` (como endpoint compatível com OpenAI).
2. **VS Code Integration**: Configuração / Extensão para permitir que o desenvolvedor invoque o `jhonny-v` diretamente do editor.

---

## 📌 Mapeamento de Issues

* **`Issue #501`**: Adicionar serviço `open-webui` ao `infra/compose.interfaces.yaml` pré-configurado para conectar na API do orchestrator.
* **`Issue #502`**: Homologar a exibição e aprovação de ações com *Human-in-the-Loop* na interface do Open WebUI.
* **`Issue #503`**: Configurar e documentar a integração da extensão VS Code com os endpoints do `jhonny-v`.
* **`Issue #504`**: Executar testes de integração End-to-End (E2E) simulando requisições do usuário desde o chat web até a execução final das ferramentas MCP.

---

## ✅ Critérios de Aceite da Milestone
- [ ] O usuário consegue interagir com a IA através do Open WebUI.
- [ ] A aprovação de ações sensíveis (*Human-in-the-Loop*) é solicitada de forma amigável na interface.
- [ ] A integração no VS Code responde corretamente a dúvidas e comandos de código.
- [ ] Todo o ciclo da requisição produz logs no Loki e traces vinculados no Tempo.
