# 🚀 Milestone v0.1: Infra Core & Observabilidade

## 📋 Objetivo
Estabelecer a infraestrutura de contêineres e serviços de suporte necessários para a execução, persistência, roteamento de modelos e monitoramento completo de telemetria (Logs, Métricas e Traces) do ecossistema `jhonny-v`.

---

## 🛠️ Componentes & Serviços Incluídos

1. **LiteLLM Proxy**: Gateway unificado de modelos (Ollama + Cloud Provider Fallbacks).
2. **PostgreSQL + pgvector**: Persistência de checkpoints de conversa e suporte a busca vetorial (RAG).
3. **Redis**: Camada de cache distribuído e gerenciamento de sessões temporárias.
4. **RabbitMQ**: Broker de mensageria para suporte a execuções assíncronas.
5. **Stack LGTMP de Observabilidade**:
   * **Promtail**: Coleta de logs das saídas `stdout`/`stderr` dos contêineres.
   * **Loki**: Indexador centralizado de logs.
   * **Prometheus**: Coletor de métricas de infraestrutura e serviços.
   * **Grafana Tempo**: Repositório de distributed tracing (OpenTelemetry).
   * **Grafana**: Painel de visualização e exploração unificado.
