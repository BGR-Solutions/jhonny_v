# 🧠 Milestone v0.3: Agent Orchestrator (LangGraph Engine)

## 📋 Objetivo
Desenvolver o motor de decisão e orquestração do agente (`apps/agent-orchestrator`), utilizando **LangGraph**. O serviço implementará o loop ReAct, gerenciamento de estado persistente e suporte nativo a aprovações humanas em ações de alto risco (*Human-in-the-Loop*).

---

## 🛠️ Funcionalidades & Arquitetura

1. **StateGraph ReAct**: Fluxo de decisão com estados bem definidos: `agent`, `tools`, `human_approval`.
2. **PostgresSaver Checkpointing**: Persistência de threads e estados de conversação diretamente no PostgreSQL (`langgraph-checkpoint-postgres`).
3. **Human-in-the-Loop (HitL)**: Interrupção (*interrupt_before*) em ferramentas sensíveis (ex: apagar arquivos, enviar e-mails).
4. **API OpenAI-Compatible**: Exposição de endpoint `/v1/chat/completions` para integração transparente com UIs e extensões.
